
# HR/IT Helpdesk Agent

## Project Description
A helpdesk chatbot developed using Python and Streamlit to answer common support-related questions.

## Technologies Used
- Python
- Streamlit

## Features
- Password reset assistance
- Order tracking
- Payment support
- Refund assistance
- Conversation history
- Clear Chat option

## Installation
Install Streamlit:

pip install streamlit

## Run the Application

python -m streamlit run app.py
